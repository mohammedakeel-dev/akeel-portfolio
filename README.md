# Mohammed Akeel - Portfolio Website

A professional portfolio website for Mohammed Akeel, built with static HTML, CSS, and a small JavaScript enhancement layer for navigation and scroll reveals.

## Sections

- Hero section with structured positioning and CTAs
- About section focused on engineering mindset and learning
- Skills grouped by category
- Project showcase covering the current AI Mental Health Companion and practical academic projects
- Education timeline
- Experience and practical learning overview
- Contact section with real portfolio and email links

## Technologies Used

- HTML5
- CSS3
- JavaScript (minimal, no library dependency)

## How to View

Open the project in a browser, or run a local static server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

## Notes

- The portfolio is intentionally authentic and avoids fabricated achievements or inflated claims.
- Resume is presented as a mail-to request rather than a fake file because no resume document was present in the project.
- Contact details and portfolio URL reflect the information available in the current project state.
